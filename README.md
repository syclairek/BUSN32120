# News Sentiment and Market Reaction Analysis

## Overview
This project explores the relationship between financial news sentiment and S&P 500 market behavior using SQL, Python, NLP, and machine learning.

We analyzed whether news sentiment can help explain short-term market returns and volatility through:
- SQL-based feature engineering
- Exploratory data analysis (EDA)
- Predictive modeling
- Volatility analysis

---

## Key Findings
- Sentiment alone showed limited predictive power for short-term returns.
- Rolling sentiment provided clearer patterns than raw daily sentiment.
- High news volume periods were associated with greater market volatility.
- News intensity appeared more related to market uncertainty than return direction.

---

## Models Used
- Linear Regression
- Logistic Regression
- K-Means Clustering

---

## Tools & Technologies
- SQL
- Python
- Pandas
- Scikit-learn
- Matplotlib / Seaborn

---

## Conclusion
Financial news sentiment alone is not sufficient for reliably predicting market returns, but news intensity and volatility-related features may provide useful insight into broader market conditions.
